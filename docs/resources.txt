How the formula was recovered
A separate ad-hoc-signed clone of the supplied app ran with network/device/
helper execution blocked and native device API responses replaced by synthetic
fixtures. The original app was unchanged. Selecting the synthetic NanoCore in
the GUI triggered the actual Dart asset loader. An observer at
FlutterMacOS+0x883948 captured2475 bytes passed to Filter_Process; zlib decoding
yielded6835-byte strings_en.json, matching entry66 length+CRC.
Decoded SHA2566948f8c683db51474ce9a94cf540c1afe69c6a0f62601dce0d97da7fb04559f7.

The backtrace led to App+0x1c2ce0 and+0x1c2df0. Static tracing showed the
global byte array, byte1 and UTF8 path entering SHA256, then repeating XOR at
+0x1c2f58. A passive read of the Dart global typed-data payload recovered S.
In this specific AOT build: *( *(x26+0x60) + 0x1600 ), data at tagged pointer
+0x17. These offsets are build-specific; they are not an external API.
The resulting mask matched the captured entry66 independently, followed by
all472 decoded CRC/length checks and472 path-derived ID checks.
